## How to use and best practices

Clone this repository in your own computer. If you are adapting or
modifying code, make sure to work on your own branch and if you have any
bug fixes you can make a pull request.

When working with the data set, make sure to **always** keep the raw
data intact. Any procedures done to clean and process the data should
generate a new file. That way, all users have access to the same raw
data set.
